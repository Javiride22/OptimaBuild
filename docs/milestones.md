# Milestones
## Milestone 0: Modelado principal del problema
Es un hito interno centrado exclusivamente en abordar el problema inicial de Alejandro en [HU001].

A partir del análisis de la necesidad descrita en [HU001] se usará la metodología de Domain Driven Design para representar y modelar el contexto del problema con las estructuras mínimas necesarias, todavía sin desarrollar la lógica de negocio. Se crean issues que representa un problema dentro del contexto y cada issue se resolverá mediante uno o varios commits, con fragmentos de código siguiendo las buenas prácticas del lenguaje elegido.

El hito se considerará alcanzado si se comprueba la trazabilidad completa del proceso, es decir, los issues proceden directamente del problema formulado en [HU001] y su journey. Cada fragmento de código resuelve uno de dichos issues. Cada commit resuelve y se enlaza únicamente con un issue, evidenciando un progreso justificado en el modelado.

## Milestone 1: Implementación de primera lógica
Es un hito interno que continúa el trabajo sobre el problema de [HU001] a partir de la base obtenida en el hito anterior.

Sobre lo trabajado en el milestone 0, los aspectos necesarios para comprobar las restricciones y reglas del problema de [HU001], además de tests que verifiquen la lógica implementada. Se dividen en problemas atómicos planteados como issues. Dichos issues guían la introducción de la lógica de negocio mínima indispensable para resolver la incertidumbre de Alejandro. 

El hito se considerará alcanzado si existe lógica sobre el modelo y se comprueba mediante pruebas automáticas que se ha desarrollado siguiendo la metodología elegida.
