# Milestones
## Milestone 0: Modelado principal del problema
En este hito se abordará el diseño y la codificación del modelo inicial del problema asociado a la [HU001], empleando la metodología Domain Driven Design.

El hito se considerará alcanzado si se ha seguido la metodología establecida (DDD), logrando plasmar la representación del problema en código.

##

## Milestone 1: Implementación de primera lógica
Se trabaja a partir de la base obtenida en el hito anterior para implementar una lógica de negocio que continúe con la resolución del problema asociado a la [HU001].

El hito se considerará completado y válido cuando una batería de pruebas automatizadas compruebe, utilizando los datos de la [HU001], que se obtienen los resultados esperados y que las restricciones del problema quedan satisfechas correctamente.
